## 当前能力

- **Nova Launcher**：桌面端入口，负责承载 Nova 的窗口和组件体验。
- **EventBus**：本机回环 TCP 消息总线，提供服务注册、RPC 请求和事件订阅。
- **Config**：独立运行的配置组件，负责登记的 TOML 文件读写、校验和变更通知。
